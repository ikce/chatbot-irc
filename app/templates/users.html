Chaque ligne = un mask IRC (nick!ident@host) avec des wildcards * et ?. Coches = permissions accordées. Un user ajouté depuis IRC ({{ command_prefix }}add user <mask>) arrive avec tous les flags décochés — tu choisis ici ce qu'il peut faire.

Keyword LLM : mot-clé qui déclenche la réponse du bot pour ce user. Vide = le bot répond quand son nick est mentionné dans le message OU en PV. Rempli = match substring case-insensitive (ex: pizza répond à « qui veut de la pizza »).
🌐 Web search : opt-in per-user, requiert aussi le kill-switch global ON dans /llm.

Wildcards utiles :
  Bob!*@* — tout ce qui provient du nick Bob
  *!*@*.videotron.ca — tous les users d'un domaine (accès par host, no nick needed)
  *!~ident@* — tous les users avec un ident précis
