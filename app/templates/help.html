📘 Commandes IRC — cheatsheet

Toutes les commandes utilisent le préfixe configuré dans / — actuellement {{ prefix }}. Chaque commande vérifie une permission du user (flag allow_* dans /users) — un user sans le flag correspondant est silencieusement refusé.

💬 Chat LLM (déclencheur par mask + keyword)

Le bot ne parle jamais tout seul. Il répond quand :

  1. Le mask du user matche un UserAcl actif dans /users ;
  2. Ce user a la checkbox 💬 LLM chat cochée (ou est 👑 Admin) ;
  3. Le keyword du user matche : soit substring dans le message, soit — si le keyword est vide — le nick du bot est mentionné dans le message OU le message arrive en PV.

Web search : effectif seulement si le kill-switch global (/llm) ET le flag per-user 🌐 Web search sont tous deux ON.

👑 Admin (flag is_admin)

CommandeEffet
{{ prefix }}add user <mask> [note...] Crée un UserAcl avec tous les flags OFF. À cocher via /users.
{{ prefix }}del user <mask> Supprime un user (mask exact requis, refuse les admins).
{{ prefix }}list users Liste en PM les users enregistrés + flags cochés + keyword.

🎨 Image gen (flag allow_image_gen)

CommandeEffet
{{ prefix }}img <description> Génère une image via OpenWebUI, upload sur Immich, retourne le lien de partage.

Config prompt + Immich : /images. Le bot capte aussi les requêtes en langage naturel type « fais-moi une image de ... ».

🧠 Mémoire PV (flag allow_llm_chat)

Toggle par user (case-insensitive sur le nick) — quand actif ET en PM, le bot injecte les N derniers tours de la conversation dans le contexte LLM.

Commande (PM au bot)Effet
{{ prefix }}pv on Active la mémoire persistante pour ce nick.
{{ prefix }}pv off Désactive (garde l'historique).
{{ prefix }}pv clear Efface l'historique (garde le toggle).
{{ prefix }}pv reset Efface + désactive.
{{ prefix }}pv status Info : on/off, nb messages, dernière activité.

📌 Mémoire long terme (flag allow_llm_chat)

Automatique : le bot reconnaît la personne (compte NickServ, sinon ident@host, sinon nick + même FAI/ident) et retient tout seul des faits durables au fil des conversations. Faits appris en PV = privés (jamais utilisés en channel). Stockés dans la base du bot, max 60 par personne. Les faits contenant un terme de la blacklist (page LLM) sont refusés.

Commande (PM au bot)Effet
{{ prefix }}mem list Liste ce que le bot sait de toi (🔒 privé, 👥 public).
{{ prefix }}mem add <fait> Retient un fait sur toi, privé (utilisé en PV seulement).
{{ prefix }}mem pub <fait> Retient un fait public sur toi (utilisable en channel).
{{ prefix }}mem about <nick> <fait> Ajoute un fait public sur quelqu'un de connecté. Signé de ton nick, la personne le voit dans son list et peut l'effacer. Max 5 par auteur et par personne.
{{ prefix }}mem lock / unlock Refuse / accepte les faits ajoutés sur toi par d'autres.
{{ prefix }}mem forget <n|all> Oublie le fait n° n, ou tout.
{{ prefix }}mem off / on Coupe / réactive la mémoire automatique pour toi.
{{ prefix }}mem who Comment le bot t'a reconnu, nicks connus.
{{ prefix }}mem import Reprend tes anciens faits stockés dans OpenWebUI.

👋 Au revoir spontané

Passif, sans commande. Quand quelqu'un annonce qu'il quitte le chat (« bonne nuit », « j'y vais », « a+ », « gtg »…), le bot lui dit au revoir sans être mentionné, après confirmation par le modèle juge. Une fois par personne et par channel toutes les 30 min. Channels réglables dans la page LLM (* = tous).

🙄 Ignore automatique

Le bot ignore quelqu'un pendant un temps (réglable, page LLM) s'il pose 3 fois la même question en 10 min ou s'il insiste après un refus. Les admins ne sont jamais ignorés.

CommandeEffet
{{ prefix }}unignore <nick> (admin) Lève l'ignore de ce nick.

🔗 URL fetch (flag allow_url_fetch)

Passif — pas de commande explicite. Quand un user autorisé poste une URL dans un chan, le bot fetch le HTML et répond en 1 à 2 lignes : titre + nom du site (OpenGraph ou <title>), puis la description (og:description / meta description).

Liens YouTube (watch, youtu.be, shorts, live) : titre, chaîne, durée (ou 🔴 EN DIRECT), vues, likes, date de publication, puis le début de la description de la vidéo.

Le format des lignes se règle dans la page LLM, carte « Aperçu des liens ». Les admins suivent la même règle : sans le flag 🔗, pas d'aperçu sur leurs liens.

Cette page est générée à partir de la config live. Les commandes custom reflètent la DB en direct.
