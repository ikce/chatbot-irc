Commandes custom

Une commande = un pattern qui match un message IRC, mappé sur une recette Python read-only. Les arguments extraits deviennent des kwargs pour la recette. Résultat formaté via output_template (str.format Python, ex: {target}: {count} incidents).

2 modes de pattern :
  Simple (facile) — écris juste flag {ip}, le bot devient {{ command_prefix }}flag <ip>. Placeholders : {nom} = un mot, {nom...} = reste de la ligne. Le préfixe est ajouté auto (courant : {{ command_prefix }}).
  Regex (avancé) — vraie regex Python avec groupes nommés (?P<arg>...). Le préfixe est prepend, tu écris flag\s+(?P<ip>\S+) (sans le ^!).
